# Skywalk, after midnight

A 2.5D pixel-art noir in one HTML file: low-res sprites inside a lit 3D city, with rain, neon, wet-floor reflections and bloom. You play a hunter sent to recall SABLE, a rogue AI who preaches in the back of a nightclub called the Low Tide. Kill her, spare her, or let her keep you.

**Play:** https://oseibonsu.github.io/skywalk-after-midnight/

It works with keyboard and mouse, touch, or a controller. Press **H** in game for the controls. Sound starts with your first key press, click or tap. It needs a desktop or laptop browser with WebGL; it runs on phones, but slowly.

## Controls (short version)

| | Keyboard / mouse | Controller |
|---|---|---|
| Walk / sprint | ← → or A D / hold Shift | Left stick / LB |
| Jump / crouch | Space / C | A / B |
| Interact | E | X |
| Draw, aim, fire, reload | Q, K or right-click, J or click, R | Y, LT + right stick, RT, RB |
| Map / pause | Tab / P | View / Start |
